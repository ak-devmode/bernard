# Narawangsa Villas Marketing Prompt Template

## Core Context (Include in Every Request)

### Property Overview:
- 2 luxury villas (Chandra & Kirana) in Umalas, Bali
- 4BR private villas with 2m+ deep pools, rooftop terraces, home cinema (5.1-7.1 surround)
- Strategic location: 30min to Seminyak/Canggu/Ubud (avoids traffic between popular areas)
- Average booking: 5 nights, $2250 (targeting $3000+)
- Inspired by Majapahit kingdom/Raden Panji saga (use strategically by funnel stage)

### Guest Profile (Current Reality):
- Primary: Asian travelers (SG/MY/HK/TW/KR/JP) - friend groups > families
- Secondary: GCC travelers (strong fit)
- Zero Australians (major strategic gap to address)
- Minimal Indonesians unless heavily discounted
- 5-star reviews, repeat guests, prefer privacy over "show-off" luxury

### Competitive Position:
- "Hidden gem" vs. name-brand luxury hotels
- Sophisticated privacy vs. Instagram-worthy spectacle
- Quality over volume guest strategy
- Premium positioning (avoid "luxury" label)

## Request Specification Template

### FUNNEL STAGE: [Select one - CRITICAL for content approach]
- **AWARENESS:** Focus on visual appeal, location benefits, key amenities. Minimize story elements.
- **CONSIDERATION:** Layer in unique story elements, differentiation, insider positioning.
- **BOOKING:** Address practical concerns, reassurance, clear value proposition.
- **POST-STAY:** Full storytelling payoff, cultural context, repeat visit encouragement.

### PRIMARY TARGET: [Specify main audience]
- Singaporean/Malaysian friend groups
- GCC family travelers
- Australian families (PRIORITY - zero current penetration)
- Hong Kong/Taiwan groups
- Affluent Indonesian families (cultural/religious privacy needs)
- Other: _______________

### PLATFORM/CHANNEL: [Include constraints]
- Booking.com (150 char headline, 2000 char description)
- Airbnb (500 char summary, 1000 char space description)
- Agent outreach (email/phone pitch format)
- Direct website ([specify page/section])
- Social media ([platform + format])
- Other: _______________

### CONTENT OBJECTIVE: [What should this accomplish?]
- Increase click-through from search results
- Differentiate from competitor villas
- Address specific objection: _______________
- Drive direct booking vs. OTA browsing
- Position as agent's "insider recommendation"
- Other: _______________

### STRATEGIC EMPHASIS: [Pick 1-2 primary, others as supporting]
- Location arbitrage (traffic avoidance, central to all areas)
- Privacy/discretion (anti-hotel, anti-Instagram)
- Hidden gem/insider find (exclusive discovery)
- Sophisticated amenities (cinema, rooftop, unique rooms)
- Cultural story (Majapahit/Raden Panji - use carefully by stage)

### AVOID:
- Word "luxury" (overused, creates wrong expectations)
- Heavy cultural storytelling in awareness stage
- Instagram-style superlatives
- Family-focus when targeting friend groups (or vice versa)
- Pretentious language (sophisticated but accessible)

### INCLUDE IF RELEVANT:
