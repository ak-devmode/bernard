# People Vault

Contacts and relationship context for Bernard's relationship nudge system.

## How It Works

Each person gets one file (lowercase-hyphenated, e.g., `dr-gita.md`). Bernard uses these files to:

1. Recognize names in incoming messages and add context to digests.
2. Track last-contact dates and nudge Alex when someone falls off the radar.
3. Surface relevant relationship context when Alex is preparing for meetings or calls.

## Rules

- **No raw PII in this directory.** Phone numbers, emails, and addresses stay out of the vault. Use role and relationship context only.
- **Alex populates these files.** Bernard can suggest new entries based on interactions, but Alex approves before creation.
- **One file per person.** Update existing files, never create duplicates.
- **Follow-up cadence is optional.** Not every contact needs a nudge schedule.

## Getting Started

Copy `TEMPLATE.md` and fill in the fields. Start with 5-10 key contacts across PMG, Kalpa, Padma Care, and personal.
