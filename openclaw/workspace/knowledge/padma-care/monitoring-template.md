### Thread Entry Format

For each thread worth responding to:

```
## [Thread #N] — [One-line topic]

- **Platform**: [Facebook / Reddit / TripAdvisor / WhatsApp digest]
- **Group**: [Group name]
- **Thread URL**: [link if available]
- **Urgency**: EMERGENCY | ACTIVE_CONFUSION | PLANNING_QUESTION
- **Conversion potential**: ADVOCACY | CONCIERGE | GENERAL
- **Approx. audience**: [thread views/replies if visible]
- **Pain point category**: [BPJS / hospital choice / insurance / emergency / bureaucracy / preventive / pediatric / dental / mental health / other]
- **Recommended response type**: DIRECT_ANSWER | TRIAGE | SOFT_REFERRAL | PASS

### Context
[2-3 sentence summary of what the person is asking and why]

### Draft Response
[Bernard drafts per response-drafting.md, loaded from voice.md and free-paid-line.md]

### Action
- [ ] Post as-is
- [ ] Edit and post
- [ ] Pass — do not respond
- [ ] Flag for team discussion
```

---

## Sorting Rules

1. **EMERGENCY** threads first — regardless of conversion potential
2. **ACTIVE_CONFUSION** with ADVOCACY/CONCIERGE potential second
3. **PLANNING_QUESTION** third
4. Within same urgency: sort by conversion potential (ADVOCACY > CONCIERGE > GENERAL)
